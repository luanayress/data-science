================================================================================
PREDICTION OUTPUT STRUCTURE
================================================================================

When predict() is called, it returns a dictionary with:

{
    'prediction': 0 or 1,                    # 0=Retained, 1=Churned
    'prediction_label': 'Retained'/'Churned',
    'probability_retained': 0.78,            # 0-1 range
    'probability_churned': 0.22,             # 0-1 range
    'confidence': 0.78                       # max(probabilities)
}

Example:
   Input: {'NumOfProducts': 2, 'Age': 35, 'Tenure': 5}
   Output: {
       'prediction': 0,
       'prediction_label': 'Retained',
       'probability_retained': 0.78,
       'probability_churned': 0.22,
       'confidence': 0.78
   }

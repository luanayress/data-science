      # Create preprocessing config
      preprocessing_config = {
          'features_used': features_to_use,
          'scaler_type': 'StandardScaler + MinMaxScaler',
          'model_type': 'GradientBoostingClassifier',
          'training_samples': len(X_train),
          'test_samples': len(X_test),
          'model_performance': {
              'accuracy': accuracy_score(y_test, y_pred_gb),
              'precision': precision_score(y_test, y_pred_gb),
              'recall': recall_score(y_test, y_pred_gb),

          }

      # Save all artifacts
      import joblib
      import os
      MODELS_DIR = os.path.join(os.getcwd(), 'models')
      os.makedirs(MODELS_DIR, exist_ok=True)
      
      joblib.dump(gb_model, os.path.join(MODELS_DIR, 'gradient_boosting_model.pkl'))
      joblib.dump(scaler_standard, os.path.join(MODELS_DIR, 'scaler_standard.pkl'))
      joblib.dump(scaler_minmax, os.path.join(MODELS_DIR, 'scaler_minmax.pkl'))
      joblib.dump(preprocessing_config, os.path.join(MODELS_DIR, 'preprocessing_config.pkl'))

FILE RELATIONSHIPS & DATA FLOW
================================================================================

Training Pipeline:
   modeling.ipynb
   └─ Trains gb_model, scaler_standard, scaler_minmax
   └─ Generates preprocessing_config
      └─ Saved by save_models.py
         └─ Creates models/ directory with 4 .pkl files

Prediction Pipeline:
   User Input (app.py)
   └─ Passes to model_deployment.py
   └─ Loads artifacts from models/
      ├─ gradient_boosting_model.pkl (make predictions)
      ├─ scaler_standard.pkl (preprocess)
      ├─ scaler_minmax.pkl (preprocess)
      └─ preprocessing_config.pkl (validate)
   └─ Returns prediction result to app.py
      └─ Displays in Streamlit dashboard

================================================================================
PREDICTION OUTPUT STRUCTURE
================================================================================

When predict() is called, it returns a dictionary with:

{
    'prediction': 0 or 1,                    # 0=Retained, 1=Churned
    'prediction_label': 'Retained'/'Churned',
    'probability_retained': 0.78,            # 0-1 range
    'probability_churned': 0.22,             # 0-1 range
    'confidence': 0.78                       # max(probabilities)
}

Example:
   Input: {'NumOfProducts': 2, 'Age': 35, 'Tenure': 5}
   Output: {
       'prediction': 0,
       'prediction_label': 'Retained',
       'probability_retained': 0.78,
       'probability_churned': 0.22,
       'confidence': 0.78
   }
